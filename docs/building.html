Building from source

On Windows the whole build is one command, .\build-windows.ps1. It needs no Linux, no WSL and no cross-compiler: just Rust and the Visual Studio C++ build tools. The same steps are in BUILDING.md at the root of the repository.

No game content is included. Halo Map Studio reads the game files of a copy of Halo: The Master Chief Collection that you own and have installed. A source build downloads nothing but Rust crates from crates.io and bundles no Halo maps, tags, textures or shaders. Source builds are under the same licence as the program (PolyForm Noncommercial 1.0.0); see Licence & commercial use.

Requirements

No CMake, git submodules, WSL, LLVM or cargo-xwin are needed, and you do not have to start from a Developer prompt. Install what is missing (the script prints these commands at the first missing item):

winget install Rustlang.Rustup
winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --add Microsoft.VisualStudio.Component.Windows11SDK.22621 --includeRecommended"

Open a new terminal afterwards so cargo is on the PATH.

Build

git config --global core.longpaths true
git clone https://github.com/Sopitive/HaloMapStudio.git
cd HaloMapStudio
.\build-windows.ps1

build-windows.cmd does the same for double-clicking or cmd.exe. The script works in Windows PowerShell 5.1 and PowerShell 7, stops at the first missing prerequisite with the command that fixes it, writes only inside the repository folder and downloads nothing itself. It checks Rust, Visual Studio, MSBuild, the C++ toolset and the Windows SDK; builds HaloMapStudioDLL.dll with MSBuild (Release|x64); runs cargo build --release --locked -p hms-app; and assembles dist\windows-x64\.

OptionEffect
-PackageAlso write dist\release\HaloMapStudio-<version>-windows-x64.zip and a .sha256.
-SkipNativeReuse an existing native\x64\Release\HaloMapStudioDLL.dll.
-DebugDebug build; stays in target\debug\.
-CleanDelete previous build output first.
-VerboseShow the MSBuild and cargo command lines and verbose output.

If PowerShell says running scripts is disabled, use build-windows.cmd.

What you get

dist\windows-x64\
  hms-app.exe              the application
  HaloMapStudioDLL.dll     the native map parser (keep it next to hms-app.exe)
  README.md  LICENSE.md  COMMERCIAL-LICENSE.md  THIRD-PARTY-NOTICES.md

This is the same set of files as the release archive. The default build is the offline viewer and editor.

Run it and point it at your game

Run dist\windows-x64\hms-app.exe. It finds an MCC installed through Steam (other library drives and Workshop maps included) by itself, and Microsoft Store / Xbox installs in the default folders when there is no Steam copy. Install Halo: Reach (and Halo 4, Halo 3 or Halo 2 Anniversary if you want those) in MCC first. For an unusual location set HMS_MCC_DIRS, as described in the FAQ; hms-app --dump-maps prints what was found. The files are read in place and never copied or modified. A GPU with DirectX 12 or Vulkan support is required.

Troubleshooting

  • Visual Studio not found, or link.exe not found. The C++ workload is missing: run the winget command above or tick “Desktop development with C++” in the Visual Studio Installer. If cargo reports linking with link.exe failed and the workload is installed, another link.exe (for example Git for Windows’ usr\bin) is first on the PATH: build from the “x64 Native Tools Command Prompt for VS 2022” or the “Developer PowerShell for VS 2022”.
  • kernel32.lib or windows.h not found. Add the Windows 10/11 SDK in the Visual Studio Installer.
  • The Rust host is x86_64-pc-windows-gnu. rustup set default-host x86_64-pc-windows-msvc, then rustup toolchain install stable-x86_64-pc-windows-msvc.
  • “path too long”, or files missing after cloning. Run git config --global core.longpaths true, clone again, and keep the folder near the drive root (for example C:\src\hms).
  • Antivirus quarantines hms-app.exe or the DLL, or the build is very slow. Freshly linked, unsigned programs are sometimes flagged. Exclude the repository folder from real-time scanning while building and restore the quarantined file.
  • The file is in use. A running hms-app.exe holds the files. Close it and rebuild.
  • The app says the native library is unavailable. HaloMapStudioDLL.dll must be in the same folder as hms-app.exe; unblock it (Properties) if it came from a downloaded archive. On another PC install the Microsoft Visual C++ Redistributable (x64).
  • No window, or a black window. Update the GPU driver; DirectX 12 or Vulkan is required.

The Windows script was written and checked on Linux and has not yet been run on every Windows setup. If a step fails on yours, please open an issue with the script output.

Linux

Needs stable Rust, a C++20 compiler, the libdeflate development files and a Vulkan-capable GPU.

./build-all.sh linux

This builds libhalomapstudio.so and target/release/hms-app; keep the two together. ./build-all.sh windows cross-builds the Windows release from Linux (cargo-xwin, clang-cl, lld-link); it is for maintainers, and Windows users should use build-windows.ps1.
