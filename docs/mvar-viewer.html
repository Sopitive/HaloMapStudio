Map variant viewer

Open a Halo map variant (.mvar) and read what is in it: who made it, which map it is for, its bounds and budget, and every placed object with its position, rotation, team, label and physics. Reach, Halo 3, Halo 4 and Halo 2 Anniversary variants are supported. Everything runs in your browser. The file is never uploaded, and this page loads no external script, font or service.

Nothing is uploaded: the file is read by this page in your browser only. This page works from the project site and when you open the saved mvar-viewer.html from disk (keep it next to its js folder).

Names (optional)

Objects are stored by palette index; the names belong to the game, so this page does not contain them. Load a palette JSON made by Halo Map Studio (variant get palette-json, see the API page) to see names.

Drag to pan or orbit, wheel to zoom at the cursor, click to select, double-click to frame. Click the map and press ? for every control.

What is a render pack, and how do I make one?

Without a pack this view draws the map bounds, a grid and one marker per object at its real position and rotation, coloured by team or physics. A render pack adds, per object type, a simplified mesh (400 triangles at most) with a basic colour, transparency mode and a tiny texture per part, so glass and shield doors are see-through, plus a coarse 128×128 height shading of the level. It stays under 2.5 MB and holds no level triangles, no full models and no full-size textures.

The pack is generated on your own computer from your own installed game with Halo Map Studio, and loaded here from disk (the page never uploads it). It is derived from game data, so keep it for yourself and do not redistribute it or put it on a web site. For a Reach or Halo 4 variant:

hms-app --exec $'loadvariant /path/to/my_map.mvar\nvariant get render-pack my_map.pack.json'

A pack is per base map: one pack serves every variant on that map. This page refuses a pack for a different map and says which ids differ.

    Notes

    • This page is read-only: it decodes, it never writes or edits a variant. To edit, use Halo Map Studio.
    • Rotations are shown as yaw / pitch / roll in degrees, derived from the stored forward and up vectors (how). Halo 3 variants have no spawn-sequence or physics field that HMS decodes, so those columns stay empty for Halo 3.
    • The decoder is hms-mvar.js (this page loads its generated plain-script build, hms-mvar.classic.js, and the map renderer hms-render.js, hms-camera.js and hms-gl.js), a port of Halo Map Studio’s own Rust decoders, tested field by field against them.
