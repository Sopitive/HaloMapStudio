Keyboard shortcuts

Verified against the v0.1.0 source (2026-09-17). In the app, Help ▸ Keyboard shortcuts… opens the same reference; the tables below mirror that window row for row, and it is the source of truth for your build.

Keys are ignored while a text field has focus. File, Edit, View and Tools actions live in the menu bar.

Camera

Hold the right mouse button over the viewport to fly. While you fly (and while a grab / rotate transform is active) the OS cursor is hidden and captured — locked in place on Windows and Wayland, confined to the window on X11 — so it cannot wander onto the side panels; it is released when you let go of the button.

KeysAction
Right-dragLook around
W A S DFly forward / left / back / right (RMB held)
E or RFly up (RMB held)
Q or FFly down (RMB held)
Shift (hold)4x fly speed (RMB held)

FFly the camera to the selected object (not flying, no text field focused)

Edit

KeysAction
Ctrl+ZUndo
Ctrl+Y or Ctrl+Shift+ZRedo
Arrow keysNudge the selection on X / Y by 0.25 wu (Shift = 1 wu)
PageUp / PageDownNudge the selection on Z by 0.25 wu (Shift = 1 wu)
[ / ]Yaw the selection by 15 deg (Shift = 45 deg)

Nudges move the selection without entering a transform; they work on any selected variant or placed object and are undoable.

Transform (Blender-style)

Viewport hovered, selection non-empty.

KeysAction
GGrab / move the selection (or drag the move gizmo)
RRotate the selection (or drag the rotate gizmo)
Shift+DDuplicate the selection and start moving the copies
X / Y / ZDuring G/R: lock to that axis (press again to unlock)
EDuring G/R: toggle world / local axes
Ctrl (hold)During G: magnet — push the selection's nearest real face flush against the nearest other face / map surface, then line the edges up (details)
Ctrl + X/Y/ZDuring G: the magnet may only travel on that axis (both directions)
Shift (hold)During G/R: precision (slow) movement
Shift+Ctrl + axisDuring a Shift+D grab: array copies along the locked axis
Wheel (while arraying)Change the array step: up = spread out, down = overlap (0.25 wu per notch)
Alt + wheel (while arraying)Fine array step (0.05 wu per notch)
Digits, - .During G/R: type an exact distance (wu) / angle (deg); Backspace edits. A - typed anywhere flips the sign, so 90- is the same as -90
Click or EnterConfirm the transform
Esc or right-clickCancel the transform (gizmo drags: Esc only)
