Keyboard shortcuts

Verified against the v0.1.0 source (2026-09-16). In the app, Help ▸ Keyboard shortcuts… opens the same reference and is the source of truth for your build.

UI is being reorganised. Menu names may differ in older builds. Where the in-app window and the code disagree, the difference is noted below.

Camera

All movement requires the right mouse button held over the viewport.

KeysAction
W A S DMove forward / left / back / right
E / RMove up
Q / FMove down
Shift (hold)Fly 4× faster
Right-dragLook around
Ctrl + wheelFly speed up / down
F (right button not held, no modifiers)Frame the selected object

Modal transform (Blender-style)

Cursor over the viewport, with a selection.

KeysAction
GGrab / move the selection
RRotate the selection
Shift+DDuplicate the selection and grab the copies
X / Y / ZLock to an axis (press again to unlock)
EToggle global / local axis space
Ctrl (hold)Magnet: snap flush to the nearest face or surface
Shift (hold)Precision (slower mouse response)
Shift+Ctrl (hold, after Shift+D with an axis lock)Array: stamp flush copies along the axis
Digits, ., -Type an exact distance (units) or angle (degrees)

Esc / right-clickCancel

Listed in the app but not functional in this build

Nudge keys move the selection without entering a transform: arrow keys on X/Y and PageUp/PageDown on Z step by 0.25 world units, [ / ] turn the yaw by 15 degrees; hold Shift for a larger step. They work on any selected variant object and are undoable.
