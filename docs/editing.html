Selecting objects

  • Left-click an object in the viewport to select it. Clicking empty level geometry clears the selection (and the status line reports the surface's material, which is handy for scripting).
  • Shift+click toggles an object in or out of a multi-selection.
  • In Select mode, left-drag draws a box; every object whose bounds overlap it is selected (Shift adds to the selection). Script: select box X1 Y1 Z1 X2 Y2 Z2 selects by a world-space box with the same test.
  • Hidden blocks. Some variant pieces draw nothing in-game (the invisible nut_blocker walls a shipped variant seals a map with): their shape is their physics hull. HMS draws that hull as an orange volume with an outline (View ▸ Show hidden-block physics hulls, on by default, persisted; script outlines on|off) and treats it as the object everywhere else too: click the hull to select the block, box-select takes every block whose hull overlaps the box, the selection wireframe is the hull, and the magnet, face mates and array duplicate use the hull's extents so copies tile edge to edge. Only pieces placed by the variant (or by you) get a hull; the map's own objects and level geometry never do.
  • Ctrl+A (or Edit ▸ Select all objects) selects every object; Edit ▸ Deselect clears.
  • Shift+A with a selection opens a small context menu at the cursor: Select all of same object type and Simulate this object's physics (for several objects: Simulate physics for selection).
  • The object list in the left panel selects too (click, Ctrl/Shift for multi, double-click to fly to the object). Each row shows the piece name, its label in quotes, its slot (#12, or new / placed), and the markers [scaled] and [shadow] when the object's pseudo-flags are in effect. An orange ! in front of a row means the object is outside playable space (hover it for the reason). The search box matches type, name, label, #slot and the markers (type scaled to list every scaled piece).
  • Delete / Backspace (or Edit ▸ Delete selected) deletes the selection. Edit ▸ Remove all placed objects clears every object from the scene, leaving the level; both are undoable.

Placing objects

Pick an item in the Add Object palette (use the filter box; items are grouped by Forge category) and drag it — or its 3D preview — into the viewport. The object follows the surface under the cursor (Forge objects, then level geometry, then imported geometry, then the ground plane) and drops when you release. It is placed with default Forge flags (spawns at start, both symmetries, normal physics), the neutral team (what the game gives every new Forge placement), inherited colour and no label, and is immediately editable and saveable. Placing is one undo step.

The palette's 3D preview is rendered through the same object path as the viewport — the loaded map's lighting, exposure and bloom — so a piece looks in the preview the way it will look once placed. Right-drag orbits the preview, the wheel zooms it.

Two multi-placement helpers live in Tools ▸ Placement tools (pick a palette item first):

  • Line tool — click a start point, then an end point: count copies (2–64) are placed evenly along the line.
  • Fill tool — click three or more outline points, then Close & fill: the polygon is grid-filled with the item at gap spacing (0.5–20 world units, at most 2000 copies).

Objects can also be placed with the script place command, including relative to or flush against another object.

Tool modes and gizmos

The floating toolbar in the viewport's top-left corner has four modes:

ModeBehaviour
SelectClick an object or drag a box. No gizmo.
MoveDraws three arrow handles (X red, Y green, Z blue) on the selection. Press-drag a handle to move along that axis; the move is applied when you release. Same as pressing G.
RotateDraws three rings. Press-drag a ring to rotate about that axis; applied on release. Same as pressing R.
Construct (C)Construction guides and CAD operations — clicks pick anchor points instead of selecting. Opens the Construction (CAD) window; closing that window returns to Select.

The hovered gizmo element highlights yellow. Keyboard transforms (G / R / Shift+D) work in every mode.

Grab / rotate / duplicate (modal transforms)

With the cursor over the viewport and something selected:

KeyAction
GGrab: the selection follows the mouse until you confirm.
RRotate about the selection's centre; mouse movement sets the angle.
Shift+DDuplicate the selection, then grab the copies. The copies become the selection.
X / Y / ZLock the transform to one world axis (press again to unlock).
EToggle between global and local (object) axes for the lock.
Digits, ., leading -Type an exact value: degrees for Rotate, world units for an axis-locked Grab. Backspace edits it. While a number is typed the mouse is ignored.
Enter or left-clickConfirm.
Esc or right-clickCancel — poses are restored and duplicates removed.

Pressing G or R during an operation switches to that operation. The OS cursor is hidden and captured while a transform is active (locked in place on Windows and Wayland, confined to the window on X11), and again while you fly with the right mouse button. Each confirmed transform is a single undo step.

Axis lock, magnet and precision

  • Magnet: hold Ctrl during a grab to snap the group's leading face flush against the nearest other object's face or level surface within 3 world units — along the locked axis in either direction, or downward when no axis is locked.
  • Precision: hold Shift to scale mouse movement down to about a sixth.
  • Array duplicate: after Shift+D with an axis locked, hold Shift+Ctrl: flush copies are stamped along the axis as the cursor travels, giving a row of touching pieces in one motion.
  • Guide snapping: when construction guides exist and Snap moves is on (see CAD), a grab without Ctrl snaps to the nearest guide end, midpoint or intersection within the snap range.

The Object panel

A floating Object window appears on the right whenever something is selected. Its header shows the object's datum id, position and Forge index. An orange ! Outside playable space strip appears above the properties when the selected object (or any object in a multi-selection: ! 2 of 5 selected objects are outside playable space) sits in a non-playable part of the map — see below; it follows the object live while you drag it. For a Forge object it shows the item's name and label, the obje tag behind the palette item (hover for its class and tag id) and a grid of editable Forge properties. Clicking a piece that belongs to the map itself (a scenery lamp post, a machine, a crate…) shows what it is instead of an editable record: Map object (scenery): Lamp Post with its full tag path, class, tag id, scenario placement index and position, all read-only; the status bar says the same on every click (Selected 0xE0000012 objects\levels\multi\…\lamp_post (scenery, tag 0x1ac4, scnr #18)). A small Copy tag path button puts the tag path on the clipboard, and hovering a row in the objects list shows the same identity.

RowMeaning

teamA drop-down of colour swatches: neutral (no team) first — the game's own team for every new placement and what "no team" means in the Forge menu — then red, blue, green, orange, purple, yellow, brown, pink, and none (unset) last (the file's distinct "unset" value, −1). New objects start neutral.

Below the grid the panel lists the object's material (diffuse and emissive bitmap tags, blend mode) for reference. Every property edit is undoable.

SCALED and SHADOW pseudo-flags

Two per-object switches control how the viewer treats a piece. They are pseudo-flags: the .mvar format has no field for them, so they are never written to the variant; your overrides are stored in the project file (.mmsproj) instead and restored when you open the project.

FlagAutomatic ruleEffect when on
SCALEDOn when the object's Forge label is scale.The spawn sequence is read as an X330 size multiplier and the piece renders at that size (the objects list shows [scaled]).
SHADOWOn for the shadow-casting gametype rule: GREEN team + scale label.The piece is drawn into the sun shadow map, so it casts a shadow over the ground and other objects ( [shadow] in the list). Vehicles, weapons and the other engine-default casters always cast regardless.

In the Object panel each checkbox shows the effective state and is tagged (auto) or (set); clicking sets an explicit override, right-clicking clears it back to automatic. With several objects selected a box whose objects disagree draws as indeterminate, and a click applies to every selected object. Scripts: set <datum> scaled on|off|default, set selection shadow on, flags.

Two global switches in Settings ▸ Lighting & rendering… ▸ Camera, render & display sit above the per-object flags: Scaled objects (off = every object at x1) and Shadow casters (Forge) (off = only the engine's default casters cast). Both default to on and are remembered between runs; the line under them counts how many objects are currently scaled / casting. When either global is off the Object panel's flags row shows a global: … reminder. Scripts: scale on|off, shadowcasters on|off; batch renders: HMS_SCALED, HMS_SHADOWCASTERS.

Objects outside playable space

A map's structure BSPs carry a flag "not normally playable space in multiplayer". An object placed inside such a BSP may be pushed back inside the map by the game when the session cycles, so the editor warns about it in three places:

  • the orange ! glyph in the objects list and the orange strip at the top of the Object panel (both follow the object's live position);
  • the save-time window: File ▸ Save and Save As… first check every variant and placed object. If any are outside, the save is held and an Objects outside playable space window lists them (piece, label, slot, BSP index and name, position). Double-click a row to select that object and fly the camera to it (the window closes and nothing is saved); Save anyway / Save As anyway proceeds with the held save; Cancel drops it. Objects you move back inside disappear from the list;
  • the script bspwarn list, which prints the map's BSP flags and the same object list; a scripted save never blocks but appends a warning to its output.

Maps without any flagged BSP never warn.

Mass edit

When several objects are selected the panel header turns orange: Forge object — editing N objects. The panel shows the first object's values; only the field you change is applied to the other selected objects — untouched fields keep each object's own value. Position is applied as a delta so the group keeps its layout, and rotation angles are applied to each object. Name, slot and parent are never copied. The same per-field behaviour is available in scripts as set selection <field> <value>.

Undo / redo

Ctrl+Z undoes, Ctrl+Y or Ctrl+Shift+Z redoes (also in the Edit menu). The stack holds 64 steps. Undoable: moves, rotations, duplicates, gizmo drags, drag-placing, deleting, every Object-panel edit, mass edits, CAD mates/anchors/mirrors, construction shapes, "simulate physics", Line/Fill placements, nudges, pseudo-flag changes and each script run (a whole run is one step; scripts can also call undo / redo themselves). Not undoable: creating or deleting construction guides, variant name/description/label-table edits, lighting settings and camera moves.

Construction (CAD) tools

Press C (or Tools ▸ Construction (CAD)…) to enter the Construct tool. The Construction (CAD) window opens with an operation picker:

OperationWhat it does
GuideClick two anchor points to draw a dotted construction guide between them. Guides have snappable ends, midpoints and mutual intersections. Box diagonals / Face diagonals add guides from the selection's bounding box in one click.
Circle / SquarePress and drag in the viewport: the press sets the centre, the drag sets the radius, release commits. Choose the plane (X, Y, Z or the clicked face), circle segments (3–256) and square rotation. Press a shape's centre to move it, or select it in the Shapes list, press G, and click to place. Centre on selection re-centres a shape on the selected objects.
CoincidentFace-to-face mating: click face A on the object you are moving, then face B on another object. The selection moves so the faces meet. turn to face (default on) rotates A so its face points into B; centre on face also aligns the two face centres (otherwise the mate is flush/coplanar and A keeps its in-plane position). Available in scripts as coincident.
AnchorClick a point: the selection's centre moves exactly onto it.
MirrorClick a point: the selection is mirrored through it across the chosen axis (X/Y/Z), optionally as a copy. Mirror about centre mirrors the selection through its own centre.

Other controls in the window:

  • Snap to: which anchor points clicks may land on — all points, corners, edge midpoints, face centres or object centres.
  • Snap moves + range: pull ordinary grabs onto nearby guide points.
  • Fill edge with an object: select the object(s) to copy, set count (1–256), optionally turn to follow, press Fill edge to lay the copies along the selected guide.
  • Place along guide with a distance, the guide list with per-guide delete, and Clear guides.
  • Show toggles the guide overlay; done returns to Select.

Simulate physics

Simulate this object's physics (from the Shift+A menu) drops the object straight down onto whatever is below it and tilts it flush to the slope — the equivalent of letting go of a piece with normal physics in Forge. Scripts call it settle.

Model Painter, Import geometry, Light bake map

  • Tools ▸ Model Painter… voxelises an .obj from the models/ folder next to the executable (resolution 4–48, size 2–200 world units) and places one copy of the selected palette item per surface voxel.
  • Tools ▸ Import geometry… loads an .obj / .glb from models/ as a persistent reference mesh you can place objects on (for example a level converted from another game). Clear imported removes it.
  • Tools ▸ Light bake map… renders a top-down map of the baked light colour a Forge piece would receive at every spot on the level, enumerates the achievable shades, and for a chosen shade finds the closest-matching positions with Move here / Camera buttons. Useful for colour-matching pieces that are lit by the lightmap.
